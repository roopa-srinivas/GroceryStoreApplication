What it does

Built around the database —
not bolted on top of it.

🗄️
Relational MySQL Schema

Normalized tables for products, categories, customers, and orders — with foreign keys and constraints that keep data consistent across every operation.

🔌
Flask REST API

A Python Flask backend bridges the database and the frontend — handling CRUD routes for inventory management and order processing cleanly and efficiently.

📦
Inventory Management

Add, update, and remove products with real-time stock tracking. Low-stock items are flagged automatically so nothing runs out unnoticed.

🛒
Web Order Processing

Customers can browse products and place orders through the storefront. Each order updates inventory atomically — no overselling, no race conditions.

🔍
Search & Filter

Query products by name, category, or price range. Backed by indexed SQL queries so results stay fast even as the catalog grows.

📊
Order Dashboard

A management view surfaces all orders with status tracking — pending, shipped, delivered — so fulfillment is always visible at a glance.

How it works

From storefront to database
in four steps.

01
Browse the catalog

The storefront fetches products from the Flask API, which queries MySQL for current inventory, pricing, and availability in real time.

02
Add to cart & order

Cart state is managed client-side. On checkout, the order payload is sent to the Flask API, which validates stock before writing to the orders table.

03
Database updates atomically

A single transaction deducts stock and inserts the order record — so inventory is always accurate, even under concurrent requests.

04
Admin views & queries

The management dashboard surfaces live inventory counts, order statuses, and low-stock alerts — all driven by SQL queries against the live database.

-- Get all low-stock items (under 10 units) SELECT p.product_name, p.stock_qty, c.category_name FROM products p JOIN categories c ON p.category_id = c.id WHERE p.stock_qty < 10 ORDER BY p.stock_qty ASC;
-- Place an order (atomic transaction) START TRANSACTION; INSERT INTO orders (customer_id, total) VALUES (44, 22.46); UPDATE products SET stock_qty = stock_qty - 2 WHERE id = 1; COMMIT;
-- Revenue by category this week SELECT c.category_name, SUM(oi.qty * p.price) AS revenue FROM order_items oi JOIN products p ON oi.product_id = p.id JOIN categories c ON p.category_id = c.id GROUP BY c.category_name ORDER BY revenue DESC;
